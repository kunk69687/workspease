# 工业级混合视觉抓取系统技术笔记

**明确目标**：梳理并记录一种融合“ICP 精配准（标准件）”与“AI 深度学习（非标杂物）”的三层架构混合视觉抓取系统，以确保抓取的泛化性与 0.1mm 级的绝对几何精度。

## 1. 核心结论
本系统采用 **感知-路由-执行** 的三级解耦架构。其核心设计哲学在于“分而治之”：对于已知 CAD 模型的目标（如周转箱），利用多起点轮询 ICP 算法实现零穿模的绝对刚性贴合；对于未知杂物，依赖 GraspNet 等 AI 获取更好的复杂环境泛化抓取。整个系统在输出端统一汇聚为标准化的 `.npy` 姿态文件，最大程度解耦了算法模型层与下游执行机构（机械臂本体）。

## 2. 核心原理与步骤

### A. 任务流控（感知与分流层）
1. **数据底座**：通过驱动层连接基于 Gemini 335LG 的双视硬件，获取完美对齐后的 RGB-D 数据帧流。
2. **场景解析**：使用 YOLOv8-Seg 提取当前作业场景下物品的像素级特征 Mask。
3. **算法路由**：当且仅当检测到标定件（例如 `BOX` 标签），分发前往 ICP 精配准分支；当为日常物（`ITEM`）则自动唤起神经网络深度通用抓取。

### B. 刚体测算与控制（以盒状标准件为例）
- **多起点轮询测算**：针对常见的方形周转箱具有的旋转轴对称性，系统显式植入 `[0°, 90°, 180°, 270°]` 四组等分夹角矩阵并行发射短平快的粗略 ICP 探测。依据 Fitness（点云贴合度评分）摘取最高得分位姿为基准收敛点。
- **专家级 ICP 拟合**：引入前面捕捉到的胜出者姿态为初始锚定项，向下执行高达 2000 轮的重构迭代，完成物理世界表面与数字空间实体 1:1 的极限叠靠。
- **基于正交基的动态约束生成**：抓取生成不需要预测，直接在已知局部 CAD 坐标上推导抓取：
  - Approach 轴绝对垂直进入（抗边缘偏移）。
  - Close 轴平行收紧大边（机械卡位死角）。
  - **下潜特调**：沿着局部法线给予 +2cm 位移补偿，强行深入物料箱壁，使得夹持底座天然悬浮。

### C. 坐标系折跃（核心反漂移资产）
点云矩阵在进入末端执行前必须要度过系统最易发生漂移的“四维度域转换”考验：
- `Raw Space` (现实宇宙)：相机最初采集出的原始视界体。
- `Mirror Space` (镜像宇宙)：为接入 Open3D 的显示规则，在运算中不得不发生轴向翻转处理的隔离层。
- `Local Space` (局部宇宙)：CAD 建模软件导出的自有 0 点宇宙。
- **破壁还原方程**：将生成的抓取首先由 `T_align` 将“局部宇宙”引渡回“镜像宇宙”，通过最后一次代换调用封装的 `flip_matrix` 解除了渲染层的视觉镜像绑定，正式落为“现实原始空间”，真正实现所见即所得。

## 3. 注意事项与依赖环境

- **使用说明与工作流链路**：
  > **⚠️ 绝对前提：激活隔离环境**  
  > 在执行任何核心流之前，必须确保进入了专属的算法虚拟环境，否则会导致 Open3D 或 PyTorch 底层 C++ 依赖崩溃。
  > ```bash
  > conda activate graspnet
  > cd ~/graspness_unofficial
  > ```

  - **Step 1: 目标采集与感知 (Perception)**  
    唤醒 Gemini 3D 相机与双核语义雷达，获取现实图像并选择需要抓取的目标编号：
    ```bash
    python capture_gemini.py
    ```
  - **Step 2: 算力路由与全自动解算 (Decision & Alignment)**  
    启动中央大脑读取参数并判定任务类型。以标准箱 (BOX) 为例，系统将自动执行“多起点轮询”与“高精度 ICP 贴合”，生成含局部下潜的绝对抓取姿态：
    ```bash
    python auto_grasp_engine.py
    ```
  - **Step 3: 视觉验收 (Visual Inspection - 调试期可选)**  
    强烈建议部署早期运行此步骤，在 3D 界面肉眼确认绿色的夹爪是否已垂直且精准地卡合在箱体物理边缘上：
    ```bash
    python view_3d_grasps.py
    ```
  - **Step 4: 物理空间折跃 (Execution Output)**  
    将完美的虚拟算法姿态转换（例如通过 ArUco 锚点）为机械臂底座域下的绝对坐标 $(X, Y, Z)$，直接供下位机执行：
    ```bash
    python transform_grasp_to_table.py
    ```
- **技术基石框架**：
  - `Python 3.8+` 核心环境，重度调用 `NumPy 1.23+` (强制使用 `@` 高速矩阵乘算支持) 与核心驱动包 `Open3D 0.15+` 承接点对点拟合引擎。
  - `PyTorch 1.12+ (CUDA版)` 用于接托 YOLO 等检测模型，保障实时性。
